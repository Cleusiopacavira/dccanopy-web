# dccanopy-web

Website do projeto DCCanopy.

## Estrutura do Projeto

```
├── css/
│   └── style.css
├── js/
│   └── main.js
├── images/
│   └── gallery/
├── index.html
├── robots.txt
├── sitemap.xml
└── netlify.toml
```

## Desenvolvimento

Para executar localmente, basta abrir o arquivo `index.html` no navegador.

## Deploy

O projeto está configurado para deploy automático via Netlify. Veja [NETLIFY_DEPLOYMENT_GUIDE.md](NETLIFY_DEPLOYMENT_GUIDE.md) para mais detalhes.
